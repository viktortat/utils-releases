# Утилиты: установщики и релизы

Здесь выкладываются готовые установщики небольших приложений для Windows. Исходный код лежит в отдельных репозиториях, тут только то, что нужно, чтобы скачать и установить.

## Окошко

**Окошко — маленькое плавающее окно с видео, которое всегда остаётся поверх остальных программ.**

Когда нужно читать документ, писать код или заполнять таблицу и одновременно смотреть обучающий ролик, вебинар или запись встречи, обычно приходится метаться между окнами или делить экран пополам. Окошко решает это: видео живёт в небольшом окне, его можно поставить в любой угол, и оно не мешает работе.

### Что оно умеет

- **Играет ролики YouTube** по ссылке: достаточно вставить её через Ctrl+V или перетащить вкладку из Chrome. Плейлисты поддерживаются, место просмотра запоминается.
- **Играет видеофайлы с диска**: перетащите файл в окно или откройте через меню.
- **Держится поверх всех окон** и не заслоняет работу: настраивается прозрачность, есть мини-режим, окно прилипает к краям экрана.
- **Режим «док»**: окно встаёт вплотную к краю экрана, а остальные программы автоматически освобождают ему место.
- **Транскрипция и заметки** под видео: текст видно рядом с роликом, клик по строке перематывает к нужному месту. Для длинных записей можно получить краткую сводку.
- **Кадры и код из видео**: из обучающих роликов по программированию можно вытащить код с экрана и сохранить его в Markdown.
- **Работает из трея** и отзывается на глобальные клавиши: Ctrl+Alt+Y прячет и показывает окно, Ctrl+Alt+Пробел ставит паузу из любой программы.
- **Обновляется само**: при запуске проверяет новую версию и предлагает поставить её в один клик.

### Кому подходит

Тем, кто учится по видео и параллельно что-то делает руками: разработчикам, аналитикам, студентам, всем, кто ведёт конспекты или повторяет за преподавателем в своей программе.

### Требования

Windows 10 или 11. Установка не требует прав администратора. Для распознавания кода из роликов YouTube дополнительно нужны yt-dlp и ffmpeg, для остального ничего ставить не надо.
